# gaokao-research · 高考与大学考试新风向研究

> 一份可核查的调研仓库：高考到底想选拔什么能力的人才。
> 所有结论都能追溯到政策原文、教育部教育考试院评析或权威媒体报道，并标注证据等级。

## 这个仓库是什么

围绕「高考与大学考试新风向」这一个主题的持续研究仓库。当前收录 2026 年（高考综合改革收官之年）的完整调研报告，覆盖两条线：

- **高考命题线**：从「知识记忆」到「核心素养」的六个转向
- **高校评价线**：从「一考定成绩」到「过程性评价 + 非标准答案考试」

报告不做观点输出，做**证据汇编 + 结论校准**：每条关键断言标注 `CONFIRMED` / 经验 / 推断三类等级，并附反方视角与可证伪预测。

## 核心结论（TL;DR）

1. **一句话**：高考正从「筛出记得多、算得快的人」转向「筛出会提问、能迁移、敢探究的人」。
2. **2026 两个硬动作**：命题「反押题、反套路」；招生「严控大类招生、原则上按专业招生」。
3. **能力画像 8 项**：三基扎实、批判性思维、提问能力、探究与创新、真实情境问题解决、信息处理与逻辑推理、科学素养 + AI 素养、价值判断与家国情怀。
4. **大学校内同步转向**：过程性评价 + 非标准答案考试；北京大学自 2025 级起校内评价不再使用绩点排名。
5. **最锋利的信号**：教育部教育考试院明言「人工智能时代，『会问』常常比『会答』更为重要」。

## 证据分级约定

报告内所有断言按三级标注，阅读时请区分对待：

| 等级 | 含义 | 例子 |
|---|---|---|
| `CONFIRMED` | 可点开官方原文逐字核查 | 教育部《关于做好 2026 年普通高校招生工作的通知》原文表述 |
| 经验 / 部分印证 | 有案例支撑，但缺系统抽样数据 | 「课堂生态已改变」——媒体报道以典型学校为主 |
| 推断 / 待观察 | 基于证据的合理外推，非官方立场 | 「这轮转向不会回摆」 |

**结论校准**（报告第 06 节）给出概率化判断、反方最可能抓的破绽、基准率对照，以及一条可证伪预测：若结论成立，2027 年高考评析应继续出现「提问 / 开放设问 / 人机协同」类表述且比重不降。

## 维护流程

本仓库遵循 [`Simiely/knowledge-base`](https://github.com/Simiely/knowledge-base) 的**单项目规范**（四件套 + 生长式拆分）：

| 场景 | 动作 |
|---|---|
| 补充新一年的政策/真题 | 更新 `index.html`，同步 `CHANGELOG.md` |
| 踩坑并解决 | 写进 `DEVELOPMENT.md`「关键问题与方案」，一坑一篇 |
| 形成跨项目通用经验 | 提炼到 knowledge-base `用户库/解决方案/` |
| 每次推送后 | 更新 `AGENTS.md` 顶部文档基线（日期 + commit hash） |

拆分阈值：`README.md` > 150 行、`AGENTS.md` > 150 词、`DEVELOPMENT.md` > 200 行时，才拆出 `docs/` 或 `rules/`。**不提前建目录。**
